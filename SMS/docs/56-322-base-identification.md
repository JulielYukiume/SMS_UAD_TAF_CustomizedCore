## 4. 结论与建议

| 项 | 结论 |
| --- | --- |
| 能否用 Beta6 当基线？ | **不能**（只有 DLL，没有源码；反编译不可行也不合规） |
| 能否用公开 `main`（51d0518）当基线？ | **可以**，且它是"可复现的最新公开源码" |
| 与 Beta6 的差距 | 很小（Beta6 发布于 08-18，公开 main 止于 08-14） |
| 建议 | 3.22.0-SMS.1 基线 = **`51d0518`**；发布时注明"基于公开 3.22 主线，非 Beta6 等价" |

## 5. 若必须与 Beta6 等价

需要向 duke 索取以下之一：

1. **Beta6 对应的提交哈希**（他自己本地仓库的 HEAD）；
2. **源码压缩包**（至少 `TweaksAndFixes/` 目录）；
3. 或者他愿意把未公开改动 push 到某条分支。

在此之前，任何"3.22.0-SMS.1"都只能声明为"基于公开主线"。
